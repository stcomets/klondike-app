# klondike-app

iPhone向けオフライン対応クロンダイク・ソリティア（PWA）。バックエンドを持たず、ハイスコアや対戦履歴は端末のローカルストレージにのみ保存され、外部には一切送信されない。

## 実装済みルール

### クロンダイク（通常モード）
- 1枚めくり（山札から1枚ずつ場札へ）、山札が尽きたら捨て札を戻して再利用（回数制限なし）
- 場（tableau）内の移動は「降順・色違い」の連続した束のみ移動可能
- 組札（foundation）は同じスートをA→Kの順で積む
- 場の一番上のカードが組札に置けるときはタップで自動的に送られる（組札に送れない場合は選択状態になり、移動先を選ぶ）
- 勝利条件：4つの組札すべてに13枚ずつ揃う

### 特殊ルール：組札不使用チャレンジ
- 組札への配置を一切禁止（UI上も無効化）
- 勝利条件：山札・捨て札を両方空にし、場のカードをすべて表向きにする（＝組札を一度も使わずに52枚全てをめくり切る）
- この勝利条件の定義は今回の実装での解釈。想定と違う場合は調整可能。

> ルールの解釈に相違があれば、`js/game.js` の `checkWin` 関数を起点に修正する。

## アーキテクチャ

素のHTML/CSS/JavaScript（フレームワーク・外部ライブラリ・CDN依存なし）。オフライン時や将来的な配信環境の制約を考えても壊れにくい構成を優先した。

```
index.html          画面構造
css/style.css        見た目（iPhone幅を基準にレスポンシブ）
js/cards.js           カード・デッキの定義（DOM非依存）
js/game.js            ルールエンジン（DOM非依存、ユニットテスト可能な純粋関数群）
js/storage.js         localStorageの読み書き（履歴・エクスポート/インポート）
js/ui.js              画面描画とタップ操作の処理（DOMを触るのはここだけ）
js/app.js             起動処理・Service Worker登録
manifest.webmanifest  PWAマニフェスト（ホーム画面追加用）
sw.js                 Service Worker（オフラインキャッシュ）
robots.txt            検索エンジンによるクロールを拒否
icons/                アプリアイコン（Pillowで生成、外部素材なし）
gen_icons.py          アイコン生成スクリプト（`python3 gen_icons.py` で再生成可能）
```

### 操作方法（タップ操作、ドラッグ不使用）
- 山札をタップ → 1枚めくる／空なら捨て札を戻す
- カードをタップ → 選択（組札に送れる場合は自動送り）
- 移動先のカード／列をタップ → 選択中のカードを移動
- 同じ場所を再タップ → 選択解除

### データ保存
- `localStorage` キー `klondike.history.v1` に対局履歴（モード・勝敗・手数・所要時間）を保存
- メニュー内「バックアップ」からJSONエクスポート／インポートが可能
- ネットワーク通信は一切行わない（Service Workerのfetchハンドラも同一オリジンのみを対象とし、リクエストを外部に転送することはない）

## 既知の技術的制約

- **iOS Safariの7日間ストレージ削除仕様**：Safariで7日間サイトを開かないと、localStorage/IndexedDB/Service Workerキャッシュが自動削除される可能性がある。ただし**ホーム画面に追加（インストール）したPWAはこの対象外**になるため、初回起動時にホーム画面追加を促すバナーを表示している。
- 上記の対策として、対局履歴のJSONエクスポート／インポート機能を用意している（万一データが消えた場合の手動バックアップ手段）。

## ローカルでの動作確認

Pythonの簡易サーバーで確認できる（Service Workerの登録にはHTTPまたはHTTPSでの配信が必要で、`file://` では動作しない）。

```bash
cd klondike-app
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## デプロイ方針

対戦履歴・ハイスコアは端末ローカルのみに保存され、リポジトリにはゲームの見た目・ロジック（静的ファイル）しか含まれない。万一公開リポジトリの内容が第三者に見られても実質的な影響はないと判断し、**ホスティングはGitHub Pages（無料アカウント、公開リポジトリ）**を使う。Cloudflare等の他サービスは不要。

1. `stcomets/klondike-app` リポジトリをPublicに変更（Settings → General → Danger Zone → Change visibility）
2. Settings → Pages → Build and deployment → Sourceを「Deploy from a branch」、Branchを`main` / `/(root)`に設定して保存
3. 数分後に `https://stcomets.github.io/klondike-app/` で公開される
4. 検索エンジンには引き続き`robots.txt`と`noindex`メタタグでクロール拒否（リポジトリ自体はGitHub上では見つかりうるが、ねらいで見つけられにくくする目的）
5. デプロイ後、実機（iPhone Safari）でホーム画面追加・機内モードでのオフライン動作を確認
